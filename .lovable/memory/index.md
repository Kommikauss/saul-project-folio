# Project Memory

## Core
- **Brand:** Saul Project (Estonian construction/renovation). High-end residential/technical, professional.
- **Stack:** React, Tailwind CSS, Framer Motion.
- **Design:** Clean, professional European contractor. Rounded cards, subtle shadows, green accent.
- **Typography:** 'Inter' for all text. SemiBold headings, Regular body, Medium buttons.
- **Colors:** Dark green primary (#2F5D50), secondary green (#3E7C6D), off-white bg (#F8F9F8), dark footer (#2B3A38).
- **i18n:** Must support Estonian (ET), English (EN), and Russian (RU).
- **Constraints:** Never use custom cursor effects or trailing elements (clean UI requirement).
